# ২য় প্রেসিডেন্ট’স রোভার স্কাউট (পি.আর.এস) অ্যাওয়ার্ড ওয়ার্কশপ ২০২৬ — কিউআর স্ক্যান পেজ

সনদের কিউআর কোড স্ক্যান করলে এই পেজটিই খুলবে। পেজে থাকছে প্রোগ্রামের তথ্য,
ওয়ার্কশপ স্টাফের তালিকা, সময়সূচি এবং যে সনদ থেকে স্ক্যান করা হয়েছে সেই
অংশগ্রহণকারীর তথ্য। সব লেখা ইংরেজিতে, সনদের সঙ্গে মিলিয়ে।

প্রোগ্রাম, স্টাফ ও সিডিউলের তথ্য ‘প্রতিবেদন - ২য় প্রেসিডেন্ট’স রোভার স্কাউট
অ্যাওয়ার্ড ওয়ার্কশপ ২০২৬’ থেকে নেওয়া।

## GitHub Pages-এ রাখার ধাপ

1. github.com-এ `gopalganjrover` অ্যাকাউন্টে লগইন করুন।
2. উপরে ডানদিকে **+ → New repository**। নাম দিন **`prs26`**, **Public** রাখুন,
   **Create repository**।
3. **Add file → Upload files** → এই ফোল্ডারের `index.html` টেনে ছাড়ুন →
   **Commit changes**।
4. **Settings → Pages** → Source-এ **Deploy from a branch**, Branch **main**,
   ফোল্ডার **/(root)** → **Save**।
5. এক-দুই মিনিট পর ঠিকানাটি সচল হবে:

   ```
   https://gopalganjrover.github.io/prs26/
   ```

## যাচাই

ঠিকানার শেষে `#C=001` যোগ করে দেখুন —
`https://gopalganjrover.github.io/prs26/#C=001` — ‘Participant Details’ ঘরে
০০১ নম্বর সনদের নমুনা তথ্য দেখাবে। সনদের কিউআর স্ক্যান করলেও একই পেজ খুলবে।

## এখনো বাকি

`index.html`-এর নিচের `<script>` অংশে `PARTICIPANTS` তালিকাটি এখনো নমুনা।
অংশগ্রহণকারীদের এক্সেল শিট পেলে সনদ নম্বর অনুযায়ী পুরো তালিকা বসানো হবে, এবং
`PROGRAMME`-এর ‘Number of participants’ ঘরটিও (এখন `………`) পূরণ হবে।
